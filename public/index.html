Como conectar o servidor

1
Instalar e gerenciar tudo no servidor (Recomendado)

Copie a pasta completa do projeto para um diretório fixo (ex.: C:\InfraWatch) no servidor Windows, dê dois cliques em Gerenciador.bat (aceite o aviso de Administrador) e escolha [1] Iniciar dashboard para instalar e iniciar os serviços automaticamente.

2
Acessar de qualquer PC ou celular da rede

Após instalar no servidor, nenhum outro dispositivo precisa rodar nada. Basta abrir no navegador:
• Pelo nome na rede: http://<nome-do-servidor>
• Pelo IP local ou VPN: http://<ip-do-servidor>

3
Nome personalizado (opcional)

Se quiser usar um apelido amigável (ex.: http://monitor.local), configure um registro de DNS local no roteador ou adicione no arquivo C:\Windows\System32\drivers\etc\hosts: <ip-do-servidor> monitor.local.

4
Usar como aplicativo no celular (Android / iPhone)

Abra o endereço da dashboard no Chrome (Android) ou Safari (iPhone) na mesma rede e toque em Adicionar à tela inicial para usar em tela cheia como um app.
